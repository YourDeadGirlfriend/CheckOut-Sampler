# CHECKOUT SAMPLER 🛒🔊

*A tiny supermarket. A bunch of samples. A questionable amount of noise.*

**CHECKOUT SAMPLER** is a browser-based sampler inspired by the sounds of everyday supermarket life. Turn ordinary audio into beats, build weird little loops, and make something out of the sounds you usually ignore.

No DAW, no complicated setup — just open it in your browser and start making noise.

## ✦ Features

- **12 sample pads** — trigger sounds directly from the interface.
- **4 independent banks** — organize and switch between your samples.
- **16-step sequencer** — build rhythmic patterns step by step.
- **BPM control** — adjust the tempo to fit your loop.
- **Custom samples** — load your own audio files.
- **Step recording** — create patterns with individual step controls.
- **WAV export** — export your creations as audio.

## ✦ Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API

No external libraries or frameworks. Just web technologies and a little bit of noise.

## ✦ Running locally

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Load some samples and start experimenting.

For the best experience, use a modern browser with Web Audio API support.

## ✦ The idea

CHECKOUT SAMPLER is a small experimental project about turning mundane sounds into music. It's part sampler, part sequencer, and part excuse to make something weird.

Made for fun, noise, and the love of strange little web projects.
